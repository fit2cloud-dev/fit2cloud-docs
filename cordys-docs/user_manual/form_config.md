## 1 表单设置


点击相应业务的「表单设置」按钮，进入自定义表单设置页面。

操作步骤 

1. **添加字段**：从左侧选择字段组件，拖拽至中间表单区域
2. **配置属性**：在右侧字段属性面板修改字段的基本信息、约束、权限等
3. **调整布局**：在表单属性中修改整体表单布局

表单字段设置

1. **下拉单选/下拉多选**
2. **显隐规则** 属性

在【表单设置】中，选择下拉单选/多选字段，通过配置“显隐规则”属性即可实现表单字段的显示和隐藏效果。

场景示例

**“线索来源”字段选择线上时，表单显示“线上来源详情“字段**

操作步骤

- 进入线索表单设
- 选择线索来源字段
- 选择“显隐规则”
- 设置规则，选择“线上”显示“线上来源详情”字段

**字段联动** 属性

在【表单设置】中，选择下拉单选/多选字段，通过配置“字段联动”属性即可实现表单字段与字段之间的联动。

目前之前的联动方式有两种：

1. **自动选择**：联动字段自动选择某个选项值
2. **限制可选范围**：限制联动字段的可选值范围

场景示例

1. **“线索来源”字段选择线下时，联动字段“线上来源详情“自动选择选项值为”线下不涉及“**

操作步骤

- 进入线索表单设
- 选择线索来源字段
- 选择“字段联动”
- 联动字段选择”线上来源详情“
- 设置规则，选择“线下”自动选择（联动字段）”线下不涉及“

2. **“线索来源”字段选择线下时，联动字段“线上来源详情“限制可选范围为”400电话“**

操作步骤

- 进入线索表单设
- 选择线索来源字段
- 选择“字段联动”
- 联动字段选择”线上来源详情“
- 设置规则，选择“线下”限制可选范围（联动字段）”400电话“

线索池设置

线索池管理是销售团队集中管理潜在客户线索的核心工具，支持对线索池的 **权限、领取规则、回收机制** 等进行精细化配置。

1. 基本信息配置

    - **线索池名称**  支持自定义，便于按业务线分类管理
    - **管理员**  负责维护线索池各项规则
    - **成员**  可从线索池领取线索的销售人员或团队，权限边界清晰

2. 线索领取规则

    支持多维度限制线索领取，防止资源被抢占或长期闲置

    - **每日领取数量** 【「不限」｜「限制」自定义数量】

    - **前归属人领取控制** 限制原跟进人重复领取相同线索

    - **新线索冷却期**  设置新入库线索的可领取等待时间，避免无序争抢

3. 线索回收规则

    用于自动回收长期未跟进的线索，保持资源的及时流转。

    - **自动回收触发条件**
    - 入库时间大于 90 天
    - 最后跟进时间大于 30 天

    - **条件组合方式**
        - 支持 **OR** 条件组合，适配不同业务流程
        - **时间类型支持**
        - **动态时间**
        - **区间时间**
 
    自动回收的定时任务在 **每天 0 点执行** 。

4. 动态时间 vs 区间时间

    4.1 概念差异

    - **动态时间**  
    相对于 **当前时刻** 的可变时间范围，会随系统时间自动更新。

    - **区间时间**  
    固定、有明确开始和结束点的时间范围，不会变化。

    4.2 对比表
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"16px 0 8px"}}>表 1  动态时间与区间时间对比</div>
    | 维度     | 动态时间                         | 区间时间                          |
    | -------- | -------------------------------- | --------------------------------- |
    | 范围特性 | 随当前时间动态变化                | 固定不变                          |
    | 表述方式 | “近 / 过去 / 本周”等相对概念       | 明确日期、明确起止点               |
    | 适用场景 | 实时筛选（如“近 7 天线索”）        | 固定周期统计（如“11 月销售数据”） |
    | 灵活性   | 高（自动随当前时间变化）           | 低（需手动调整）                   |


5. 动态时间 vs 动态-自定义

    5.1 动态时间

    基于「自然时间周期」自动计算的可变化时间范围。

        示例：动态-上季度

        - 当前时间：2025-12-10
        - 当前季度：Q4（10–12 月）
        - 上季度：2025-07-01 ～ 2025-09-30

        时间会随系统时间自动滚动  

        例如：2026-01 时，“上季度” → **2025-10 ～ 2025-12**

    5.2 动态-自定义

    基于当前系统时刻的自定义位移时间点/时间段。

        示例：动态-自定义「30 天前」
    
        - 当前时间：2025-12-10
        - 计算结果：2025-11-30

        系统以当前时间为基准回溯 30 天，每次查询都会自动更新。

## 3 记录/计划评论功能设置

### 3.1 记录/计划新增评论功能

- 在详情和跟进记录下方增加评论入口

![业务规则设置](/img/cordys/user_manual/Opportunity_Stage_Settings3.png)

- 点击 + 或右上评论 弹出新建评论窗口（样式以交互为准），第一版评论使用多行文本， 无需支持富文本。
    - 新建评论 默认文案“输入评论，支持@他人”
    - 回复评论 默认文案“回复XX”
    - @他人时展示全部人员下拉列表

![业务规则设置](/img/cordys/user_manual/Opportunity_Stage_Settings4.png)

- 评论展示
    - 评论默认按时间倒序排列
    - 多条评论以分隔线分隔
    - 评论结构为两级展示：（点击+ /评论）创建的评论为一级，回复评论为二级， 多个回复评论并列二级展示，回复评论默认展示一条，展开查看全部。

        - 有本条记录/计划数据权限的人员可以添加/回复评论（即：能看到记录/计划的人就能添加/回复评论）

### 3.3 通知

添加评论后触发消息通知给记录/计划负责人以及被@ 人员。
消息模板：

- 通知负责人：【添加评论提醒】评论发起人 给线索名/客户名/商机名 的跟进记录/跟进计划添加了评论
- 通知被@人员： 【添加评论提醒】评论发起人 给线索名/客户名/商机名 的跟进记录/跟进计划添加了评论并@了你
- 线索名/客户名/商机名支持跳转到详情页（最好是直接打开这条记录的详情）

### 3.4 权限

- 因记录/计划没有单独模块，有线索、客户、商机 的资源查询权限即可添加评论
- 评论创建人可以删除自己的评论，删除自己的评论时如存在回复的评论也会一起删除

### 3.5 涉及页面

- 顶部记录/计划列表
- 各资源详情页记录/计划

### 3.6 移动端

- 移动端首页需增加计划/记录列表（仅展示时光轴，无需展示列表），并支持评论
- 移动端资源详情页需增加评论功能

### 3.7 日志

增、删、改评论需要记录日志
