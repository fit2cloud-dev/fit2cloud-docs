我的待办把散落在各业务模块、需要“我”处理的事项集中到一个面板中，对应顶栏的待办入口与工作台首页的“我的待办”卡片。对成员而言，它回答了“现在该处理什么”；对管理者而言，通过待我审批与我发起的分类，可以快速判断审批链路上是否有积压。

## 1 功能简介

我的待办按**事项来源**划分为四个分组：

- **待我审批**：需要当前账号审批的单据，进一步细分为报价单、合同、发票、订单四类。
- **我处理的**：当前账号已经处理过的审批事项。
- **我发起的**：当前账号发起、等待他人处理的单据。
- **抄送我的**：审批流程中抄送给当前账号的单据，仅需知晓、无需处理。

每个分组左侧显示该分类下的待处理数量，点击后右侧展示对应的单据列表；列表顶部提供关键词搜索与视图切换，无数据时显示“暂无数据”。

## 2 入口位置

在系统顶栏点击待办图标，页面右侧打开“我的待办”抽屉，默认选中“待我审批 › 报价单”。

## 3 查看与处理待办

打开抽屉后，按以下步骤定位并处理事项：

1. 在左侧分组中展开“待我审批”，选择具体单据类型（报价单、合同、发票或订单）。
2. 右侧列表展示该类型下的待审批单据，可通过“通过名称搜索”按名称过滤。
3. 点击列表中的单据名称进入详情，执行通过或驳回等审批操作。
4. 需要查看自己发起或仅被抄送的单据时，切换到“我发起的”“抄送我的”分组。

:::note[说明]
分组后的数字代表当前待处理数量；当某个分类下没有数据时，右侧列表区显示“暂无数据”，表示该分类当前无待处理事项。
:::
