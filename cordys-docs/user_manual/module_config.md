模块配置管理用于按企业实际业务裁剪 Cordys CRM 的功能范围：一方面决定**左侧主导航**与**顶部导航**中出现哪些入口、以什么顺序排列，另一方面决定各业务模块是否启用，并集中提供各模块的表单、公海、状态流等设置入口。

## 1 功能简介

模块配置页面分为左中右三个区域：

- **主导航配置**：控制左侧导航栏的模块清单与排序，开关关闭后成员在主导航中看不到该模块。
- **顶部导航配置**：控制顶栏的功能入口，如搜索、待办、记录/计划。
- **模块配置**：列出全部业务模块，每个模块提供启用开关以及该模块下的表单与规则设置入口。

导航项采用**拖拽排序**，调整后立即对全部成员生效，因此建议在企业业务范围稳定后再统一调整。

## 2 入口位置

在左侧导航点击 **系统 › 模块配置**，进入模块配置页面。

## 3 配置主导航

“主导航配置”区域列出了全部可用的导航项，可通过拖拽调整显示顺序，右侧开关控制整组导航的显示与隐藏。可配置项包括：首页、标讯、线索、客户、商机、合同、订单、产品、仪表板、自定义表单、智能体、系统。

“顶部导航配置”区域用于调整顶栏入口，可配置项包括搜索、待办、记录/计划，部分项带有“更多”链接用于进一步设置。

## 4 配置业务模块

右侧“模块配置”区域按模块列出卡片，每个卡片右侧提供启用开关，卡片内部直接给出该模块的设置入口。

各模块提供的设置入口如下：

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"16px 0 8px"}}>表 1  各模块的设置入口</div>

| 模块 | 设置入口 |
|---|---|
| 首页 | — |
| 标讯 | — |
| 线索 | 线索表单设置、线索池设置、线索库容设置、更多 |
| 客户 | 客户表单设置、联系人表单设置、公海设置、更多 |
| 商机 | 商机表单设置、报价表单设置、商机阶段设置、更多 |
| 合同 | 合同表单设置、回款计划表单设置、回款记录表单设置、更多 |
| 订单 | 订单表单设置、订单状态流 |
| 产品 | 产品表单设置、价格表表单设置 |
| 仪表板 | — |
| 自定义表单 | — |
| 智能体 | — |

其中表单设置用于自定义该模块的字段与布局，操作见[表单设置](./form_config.md)。线索池与库容见[线索池与库容](./lead_pool.md)，公海见[公海设置](./open_sea.md)，商机阶段见[商机阶段设置](./opportunity_stage.md)，订单状态见[订单状态流](./order_status.md)。左侧导航中的自定义表单模块见[自定义表单](./custom_form.md)。

:::warning[警告]
关闭模块后，成员在主导航中找不到该模块，已在库的数据不会删除但无法通过菜单进入，请谨慎操作。
:::

:::note[说明]
新增或调整表单字段后，前端表单会同步更新。字段变更会影响已有数据的展示，建议在业务低峰期进行。
:::
