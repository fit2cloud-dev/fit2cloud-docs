---
title: 角色权限
description: 介绍 Cordys CRM 角色的数据权限、功能权限与成员分配。
---

角色权限管理决定成员能看到哪些数据、能操作哪些功能。同一名成员的数据范围由角色上的数据权限决定，按钮是否出现由功能权限决定。

## 1 功能简介

页面左侧是角色列表，可按名称搜索。系统预置了销售经理、销售专员、普通管理员等角色，也可继续添加。选中角色后，右侧分为“权限”和“成员”两个页签。

## 2 入口位置

在左侧导航单击 **系统 › 角色权限**。

## 3 数据权限

数据权限决定该角色能查询的数据范围，四选一：

- **全部数据**：可查看企业内该模块的全部记录。
- **本部门数据**：只能查看所属部门的记录。
- **仅本人数据**：只能查看自己负责或创建的记录。
- **指定部门数据**：只能查看被点名的部门的记录。

## 4 功能权限

功能权限按“功能 / 操作对象 / 权限”三列配置，勾选后成员才能看到对应菜单或按钮。权限按业务分组，主要包括：

- **系统管理**：组织架构、角色权限、模块设置、消息设置、企业设置、系统日志、License、流程设置。组织架构另有导入、同步、重置密码；角色权限另有添加用户、移除用户。
- **客户管理**：客户、公海、联系人。客户包含转移、移入公海、导入、导出、合并；公海包含领取、分配。
- **线索管理**：线索、线索池。线索包含转移、移入线索池；线索池包含领取、分配。
- **商机管理**：商机、报价。商机包含转移、反签；报价包含下载、作废。
- **合同管理**：合同、回款计划、回款记录、工商抬头、发票记录。合同另有合同阶段变更、回款。
- **订单管理**：订单的查看、添加、编辑、删除、下载、导入、导出。
- **产品管理**：产品、价格表。
- **其他**：仪表板、标讯、智能体、自定义表单，以及个人信息中的 API Keys。

未勾选的操作不会出现在该角色成员的界面上。

## 5 添加成员

切换到“成员”页签，把组织架构中的成员加入当前角色。一名成员的实际权限等于其所属角色的数据权限与功能权限之和。调整后，该成员重新进入对应页面即可生效。
