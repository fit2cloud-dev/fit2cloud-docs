title: 订单状态流
description: 介绍 Cordys CRM 订单状态的名称、状态类型，以及流转配置的入口。

订单状态流规定一张订单从新建到完成或作废要经过哪些状态。销售在订单详情中能切换到的状态，以及这些状态属于进行中还是已经完结，都在这里维护。

## 1 功能简介

设置页有两个页签。**状态配置**维护状态名称和类型；**流转配置**规定这些状态之间能否前进或回退。合同阶段使用同一类配置方式。

## 2 入口位置

在左侧导航单击 **系统 › 模块配置**，在“订单”卡片中单击“订单状态流”。

## 3 状态配置

每一行是一个订单状态：

- **订单状态**：成员在订单上看到的状态名。示例中为新建、待发货、部分发货、已发货、待验收、已完成、已作废。
- **状态类型**：进行中或完结。已完成、已作废属于完结，其余属于进行中。

拖拽手柄调整顺序。进行中的状态可以编辑或通过更多菜单删除；完结状态保留编辑。成员如何在订单上变更状态，见[订单管理](./order.md)。

## 4 流转配置

切换到“流转配置”页签，设置状态之间允许的跳转。只保留状态列表而不配置流转时，成员在订单上无法按预期切换状态。调整流转规则前，先确认当前订单不会停在即将被删掉的状态上。
