title: 跟进记录计划

---

跟进记录计划用于集中管理销售过程中的跟进动作：**跟进记录**沉淀已经发生的沟通内容，**跟进计划**安排待执行的跟进任务。两者统一收敛在顶栏的“记录/计划”入口中，销售无需逐条打开客户详情，即可在同一个面板里查看和整理自己的跟进节奏，管理者也可以按部门维度掌握团队执行情况。

## 1 功能简介

记录计划面板由**跟进记录**和**跟进计划**两个页签组成，页签内均提供视图切换、关键词搜索和行内操作，支持按个人、部门或自定义视图组织数据。

**跟进记录**用于记录已完成的跟进，列表按客户维度展示跟进类型、关联商机、联系人与跟进方式，并保留详情、编辑、删除操作。**跟进计划**在记录字段基础上增加**状态**维度，通过“全部 / 未开始 / 进行中 / 已完成 / 已取消”快速筛选，行内提供详情、编辑、删除与更多操作。

## 2 入口位置

在系统顶栏点击“记录/计划”图标，页面右侧打开记录计划面板，默认停留在“跟进记录”页签。

## 3 跟进记录

跟进记录页签的列表字段与操作如下：

- **视图切换**：支持“所有记录 / 我的记录 / 部门记录”，点击“+ 新建视图”可基于当前筛选条件保存自定义视图；右上角的视图下拉用于在已保存视图之间切换。
- **列表字段**：序号、客户名称（公司名称）、跟进类型、商机、联系人、跟进方式。
- **行内操作**：详情、编辑、删除。点击“详情”查看该条跟进记录的完整内容。

列表顶部提供“通过名称搜索”输入框，支持按名称快速过滤当前视图内的记录；底部显示命中总条数。

## 4 跟进计划

切换至“跟进计划”页签后，除视图与搜索能力外，额外提供按状态筛选的快捷页签。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/cordys/user_manual/followup-plan.png" alt="图 2  跟进计划列表" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2  跟进计划列表</div>

- **状态筛选**：全部、未开始、进行中、已完成、已取消；状态同时以彩色标签展示在列表的“状态”列中。
- **视图切换**：支持“所有计划 / 我的计划 / 部门计划”，同样可通过“+ 新建视图”沉淀自定义视图。
- **列表字段**：序号、客户名称（公司名称）、状态、跟进类型、商机、联系人。
- **行内操作**：详情、编辑、删除；部分记录还会出现“更多”菜单，用于执行状态流转等附加操作。

:::note[说明]
跟进记录与跟进计划共用“新建视图”能力，把常用的筛选条件保存为视图后，每次进入面板可直接复用，无需重复设置条件。
:::

## 5 评论

跟进记录和跟进计划都支持评论。在列表中打开一条记录的“详情”，底部展示评论数量；单击“添加评论”后输入内容。首页“我的计划”和[个人中心](./personal_center.md)的“我的计划”页签使用同一套评论入口。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/cordys/user_manual/followup-comment.png" alt="图 3  添加评论" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3  添加评论</div>

- **输入评论**：输入框提示“输入评论，支持@他人”。输入 `@` 后可选择要通知的成员。
- **确认 / 取消**：单击“确认”发表评论，单击“取消”关闭输入框。
- **通知**：评论发表后，系统通知该跟进记录或跟进计划的负责人；评论中被 @ 的成员也会收到提醒。

能看到这条跟进记录或跟进计划的成员可以添加和回复评论。评论创建人可以编辑、删除自己的评论。
