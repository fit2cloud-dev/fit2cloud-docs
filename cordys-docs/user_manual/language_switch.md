---
title: 中英文切换
description: 介绍 Cordys CRM 中英文界面切换的入口、可选语言与切换后的界面变化。
---

Cordys CRM 内置中英文两套界面语言，同一套业务数据在两种语言下均可正常读写。对于有海外团队或外籍成员的企业，成员无需额外安装语言包即可切换到英文界面，便于跨国协作时统一操作口径。

## 1 功能简介

语言切换作用于**界面文案**层面，不改变业务数据本身。切换入口位于系统顶栏最右侧的语言图标，下拉菜单中列出当前支持的语言并标记当前生效项：**中文** 与 **English**。选择后界面立即刷新，无需退出登录或刷新浏览器。

由于切换仅影响界面文案，模块名称、按钮、提示语等会随语言同步变化，而客户名称、商机名称等用户录入的数据内容保持原样。

## 2 入口位置

在系统顶栏点击最右侧的语言图标，展开语言下拉菜单，当前生效语言前会显示对勾。

## 3 切换后的界面变化

选择 English 后，界面文案整体切换为英文，左侧导航、工作台卡片与统计口径均同步更新。

主要区域的对照关系如下：

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"16px 0 8px"}}>表 1  中英文界面文案对照</div>

| 中文界面 | 英文界面 | 说明 |
|---|---|---|
| 我的看板 | My Dashboard | 顶部页签名称 |
| 首页 / 标讯 / 线索 / 客户 / 商机 / 合同 / 订单 / 产品 | Home / Tender / Lead / Account / Opportunity / Contract / Order / Product | 左侧主导航模块 |
| 仪表板 / 自定义表单 / 智能体 / 系统 | Dashboard / Custom Form / Agent / Settings | 左侧主导航模块 |
| 数据概览 | Data overview | 工作台统计区标题 |
| 快捷入口 | Quick access | 工作台快捷操作区标题 |
| 我的待办 | My tasks | 工作台待办区标题 |
| 我的计划 | My plan | 工作台计划区标题 |
| 消息通知 | Notification | 工作台消息区标题 |

:::note[说明]
语言选择是**按账号**生效的个人偏好，成员之间的选择互不影响；如需恢复到中文界面，重新打开语言菜单选择“中文”即可。
:::
