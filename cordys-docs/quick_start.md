## 1 快速部署


可以通过 1Panel 应用商店快速安装 Cordys CRM：

```
http://目标服务器 IP 地址:8081

用户名：admin

默认密码：CordysCRM
```

注意：详细步骤参考 [**1Panel 快速安装 Cordys CRM**](./installation/1panel_installtion) 。

如果是用于生产环境，推荐使用 [**离线包方式**](./installation/offline_installtion) 进行部署。

## 2 界面介绍


Cordys CRM 主界面导航栏包含：【首页】、【标讯】、【线索】、【客户】、【商机】、【合同】、【订单】、【产品】、【仪表板】、【智能体】和【系统】。

左侧为功能导航区域支持功能模块的快速切换，当集成 BI 工具 DataEase 后，开启 【仪表板】导航页。

![导航栏](/img/cordys/index/home2.png)

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 1  导航栏</div>


### 首页

    
支持数据概览和快速入口

    
![首页](/img/cordys/index/home2.png)

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2  首页</div>
    ### 线索

    
对“潜在客户”从初次接触到转换为正式客户的全流程追踪和管理，支持自定义线索表单，一键转换线索，帮助企业提升线索转化效率。
    
![线索](/img/cordys/index/lead2.png)

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3  线索</div>
    ### 客户

    
对已转化的“正式客户”的全生命周期管理，支持自定义客户表单、多成员协同跟进客户，以及对客户的联系人管理。
    
 ![客户](/img/cordys/index/account2.png)

 <div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 4  客户</div>
    ### 商机

    
对“有明确购买意向的客户”从“需求确认”到“最终成交（或流失）”的全流程跟踪和管控，支持自定义商机表单、商机阶段管理。
    
 ![商机](/img/cordys/index/opportunity2.png)

 <div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 5  商机</div>
    ### 合同

    
用于管理合同履约与回款相关数据，涵盖回款计划、回款记录、工商抬头及发票记录等子模块，支持合同回款节点管理、资金回收跟踪及开票信息维护，确保合同执行过程在 CRM 中闭环、可追溯。
    
 ![合同板块](/img/cordys/user_manual/contractPaymentRecord12.png)

 <div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 6  合同板块</div>
    ### 订单

    
用于管理合同履约执行数据，关联合同信息，覆盖订单创建、交付、验收与收款环节，支持履约进度跟踪与状态同步，保障业务执行规范可追溯。
    
 ![订单板块](/img/cordys/user_manual/ordercreate.png)

 <div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 7  订单板块</div>
    ### 产品

    
对企业销售的产品/服务进行标准化管理，支持自定义产品表单以及产品管理功能。
    
 ![产品](/img/cordys/index/product2.png)

 <div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 8  产品</div>
    ### 智能体

    
支持嵌入第三方智能体平台MaxKB，基于CRM数据创建高效智能体应用， 如智能创建（线索/客户/商机/联系人）、智能录入（跟进记录）、智能查重等。
    
![智能体](/img/cordys/index/agent2.png)

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 9  智能体</div>
    ### 系统

    
包含组织架构、角色权限、模块配置、消息管理、企业设置以及系统日志功能。
    
 ![系统](/img/cordys/index/set2.png)

 <div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 10  系统</div>
