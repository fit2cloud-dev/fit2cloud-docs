本页汇总 MaxKB 技术交流群中用户咨询频率较高的常见问题及处理方式，内容持续更新。

## 1 知识库与模型

### 1.1 标题内容检索不出来怎么办？

**问题**：知识库文档分块后，用与标题完全一致的内容做命中测试检索不出来，必须生成关联问题才能命中，有办法不生成关联问题也能命中吗？

**处理方式**：

可先检查命中测试的相似度参数是否设置过高，适当调低相似度后重新检索；若仍无法命中，可为分段添加关联问题，或更换效果更好的向量模型。

### 1.2 如何关闭模型的思考模式？

**问题**：MaxKB 里怎么关闭模型的思考模式？

**处理方式**：

在模型的【模型参数设置】中可添加参数，关闭模型本身的思考模式。

### 1.3 llama.cpp 重排模型添加提示 URL 无效怎么办？

**问题**：用 llama.cpp 部署的重排模型，在 MaxKB 添加时提示 URL 无效，是什么原因？

**处理方式**：

Ollama 和 llama.cpp 的重排模型校验接口不一样，因此选择 Ollama 供应商不一定可以通过校验。添加时供应商选择 `vLLM` 进行校验即可。

### 1.4 知识库错误命中相似分段怎么办？

**问题**：知识库检索时错误命中了相似但不相关的分段，如何避免？

**处理方式**：

可在命中测试中调低相似度、调整返回分段数 TOP 等参数，对分段进行再次编辑或添加关联问题，以提升和优化回答效果；关联问题可批量让 AI 生成。若没有匹配到分段，可设置判断器直接回复无法回答。

详细步骤请参阅[命中测试](../user_manual/dataset/hit-testing.md)。

### 1.5 工作流调用 MCP 卡死怎么办？

**问题**：工作流中某个节点给 MCP 发消息后一直卡住、后台显示 0 且无历史记录，是什么原因、怎么避免？

**处理方式**：

SSE 协议读取响应没有超时，会导致工作流调用 MCP 时卡住。将 MCP 的调用协议改为 Streamable HTTP 即可解决，不建议通过加重试来规避（重要操作盲目重试可能带来安全问题）。

### 1.6 知识库如何复制到其他工作空间？

**问题**：知识库文件已向量化，如何复制一份到其他工作空间？

**处理方式**：

通过导出再导入的方式实现。

### 1.7 Skill 如何读取服务器目录？

**问题**：在 MaxKB 的 Skill 中想读取服务器上某个目录，直接写路径可以吗？

**处理方式**：

MaxKB 的 Skill 是上传的 ZIP 包，运行时被解压到按会话隔离的临时目录（`/tmp/<chat_id>/skills`），对 Agent 暴露为虚拟路径 `/skills`，该目录在本次会话结束后即被删除，且 Skill 内脚本以受限的 sandbox 用户执行，因此不能依赖它读写持久数据，也不存在 `input/`、`output/` 之类的标准数据目录约定。

### 1.8 工作流调用智能体如何传递多个参数？

**问题**：在工作流中调用智能体时，除了用户问题参数，怎么传递多个参数？

**处理方式**：

在【基本信息】页定义会话变量，在节点后补一个【变量赋值】节点，把需要的参数赋进变量内，即可实现多参数的存储与复用。

### 1.9 如何输出重排后的第一个分段内容？

**问题**：高级智能体里回复节点想输出重排后的第一个分段内容，变量该怎么配置？

**处理方式**：

把重排节点的「引用分段 Top」设为 1，回复节点的内容配置直接 copy 重排节点输出参数中的重排结果即可。


## 2 系统集成与权限

### 2.1 WorkBuddy 与 MaxKB 如何关联？

**问题**：WorkBuddy 的登录账号需要通过 MaxKB 创建吗？两个账号的权限是怎么关联的？

**处理方式**：

WorkBuddy 账号与 MaxKB 账号相互独立，通过 MaxKB 的个人 API Key 对接。安装 Skills 后，在技能中配置 MaxKB 的个人 API Key，WorkBuddy 即基于该 MaxKB 个人账号的权限访问对应知识库；首次使用时 AI 会向你索要登录所需的凭证（即 MaxKB 的个人认证信息）。

### 2.2 MaxKB 对接WorkBuddy 的 Skills 在哪里下载？

**问题**：MaxKB Skills 技能包从哪里获取？下载后 WorkBuddy 不识别怎么办？

**处理方式**：

MaxKB Skills 可在论坛帖子（https://bbs.fit2cloud.com/t/topic/19883）中获取下载链接。下载后把安装包直接拖入 WorkBuddy 的输入框，让 WorkBuddy 自行安装即可。

## 3 安装与升级

### 3.1 MaxKB 如何升级版本？

**问题**：MaxKB 怎么升级到新版本？

**处理方式**：

升级前请先对数据进行备份。在线安装的按在线升级步骤操作：先执行 `docker pull registry.fit2cloud.com/maxkb/maxkb` 下载最新镜像，再查看并确认上一次数据持久化目录，删除旧版本容器后以相同的数据持久化目录启动新版本容器。离线安装的请参阅离线升级文档。

详细步骤请参阅[在线升级](../installation/online_installtion.md)与[离线升级](../installation/online_installtion.md)。
