## 2 知识库与模型

### 2.1 标题内容检索不出来怎么办？

**问题**：知识库文档分块后，用与标题完全一致的内容做命中测试检索不出来，必须生成关联问题才能命中，有办法不生成关联问题也能命中吗？

**处理方式**：

可先检查命中测试的相似度参数是否设置过高，适当调低相似度后重新检索；若仍无法命中，可为分段添加关联问题，或更换效果更好的向量模型。

### 2.2 如何关闭模型的思考模式？

**问题**：MaxKB 里怎么关闭模型的思考模式？

**处理方式**：

在模型的【模型参数设置】中添加参数，关闭模型本身的思考模式。

### 2.3 智能问答输出 token 被截断怎么办？

**问题**：已经在大模型参数设置里把最大 token 拉到最大值，智能问答输出还是大概 3000 个 token 就被截断，是哪里设置的问题？

**处理方式**：

先确认模型参数设置中是否已配置对应参数；若已设置仍被截断，可更换其他模型再试，仍不行则提供执行详情或工作流截图进一步排查。

### 2.4 llama.cpp 重排模型添加提示 URL 无效怎么办？

**问题**：用 llama.cpp 部署的重排模型，在 MaxKB 添加时提示 URL 无效，是什么原因？

**处理方式**：

Ollama 和 llama.cpp 的校验接口不一样，因此选择 Ollama 供应商无法通过校验。添加时供应商选择 `vLLM` 进行校验即可。

## 4 系统集成与权限

### 4.1 WorkBuddy 与 MaxKB 账号如何关联？

**问题**：WorkBuddy 的登录账号需要通过 MaxKB 创建吗？两个账号的权限是怎么关联的？

**处理方式**：

WorkBuddy 账号与 MaxKB 账号相互独立，通过 MaxKB 的个人 API Key 对接。安装 Skills 后，在技能中配置 MaxKB 的个人 API Key，WorkBuddy 即基于该 MaxKB 个人账号的权限访问对应知识库；首次使用时 AI 会向你索要登录所需的凭证（即 MaxKB 的个人认证信息）。

### 4.2 MaxKB 技能怎么下载并安装到 WorkBuddy？

**问题**：工具商店里的 MaxKB RAG-QA 技能怎么下载并安装到 WorkBuddy？

**处理方式**：

在工具商店中点击对应技能（如 MK 的 RAG-QA 技能）直接下载，然后把下载得到的文件拖入 WorkBuddy 的输入框，让 WorkBuddy 自行安装即可。
