## 2 知识库与模型

### 2.1 标题内容检索不出来怎么办？

**问题**：知识库文档分块后，用与标题完全一致的内容做命中测试检索不出来，必须生成关联问题才能命中，有办法不生成关联问题也能命中吗？

**处理方式**：

**处理方式**：可先检查命中测试的相似度参数是否设置过高，适当调低相似度后重新检索；若仍无法命中，可为分段添加关联问题，或更换效果更好的向量模型。

### 2.2 如何关闭模型的思考模式？

**问题**：MaxKB 里怎么关闭模型的思考模式？

**处理方式**：

**处理方式**：在模型的【模型参数设置】中添加参数，关闭模型本身的思考模式。

### 2.3 智能问答输出 token 被截断怎么办？

**问题**：已经在大模型参数设置里把最大 token 拉到最大值，智能问答输出还是大概 3000 个 token 就被截断，是哪里设置的问题？

**处理方式**：

**处理方式**：先确认模型参数设置中是否已配置对应参数；若已设置仍被截断，可更换其他模型再试，仍不行则提供执行详情或工作流截图进一步排查。
