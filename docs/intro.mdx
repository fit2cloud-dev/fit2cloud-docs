# 帮助中心

欢迎来到统一文档门户的帮助中心。

这里是门户自身的说明文档，产品文档请从顶部导航的「产品文档」进入。

## 门户功能

- **多产品聚合**：1Panel、JumpServer、DataEase、MaxKB 的文档统一在一个站点呈现
- **全局搜索**：右上角搜索框可跨所有产品检索
- **独立侧边栏**：每个产品有自己的文档导航
- **中英双语 + 版本切换**：右上角可切语言；1Panel / JumpServer 文档支持历史版本切换
