# Help Center

Welcome to the help center of the unified documentation portal.

This is the portal's own documentation. Access product docs from the "Products" menu in the top navigation.

## Portal Features

- **Multi-Product Aggregation**: 1Panel, JumpServer, DataEase and MaxKB docs unified in one site
- **Global Search**: the search box at the top-right searches across all products
- **Independent Sidebars**: each product has its own documentation navigation
- **Bilingual & Versions**: switch languages at top-right; 1Panel / JumpServer docs support historical versions
