## 1 项目概览

:::note

点击【工作台】进入工作台首页，有近3天、近7天、自定义时间的项目概览情况。

:::

![!缺陷创建](/img/metersphere/workstation/index/自定义时间.png)

图 1  自定义时间

:::note

自定义时间，选择项目，页面自动显示筛选后的数据。

:::

![!jira默认模板填写内容](/img/metersphere/workstation/index/展示项目数据.png)

图 2  展示项目数据
