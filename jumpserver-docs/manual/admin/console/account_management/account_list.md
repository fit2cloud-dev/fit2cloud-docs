## 1 功能简介

账号列表用于托管资产上的登录账号，包括创建、模版添加、导入导出、查看与维护密文，以及按资产或类型筛选。管理员还可使用虚拟账号，在授权时按规则选择登录身份。

路径：登录后选择 **控制台 > 账号管理 > 账号列表**。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_01.png" alt="图 1  账号列表" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 1  账号列表</div>

页签包括 **普通账号** 与 **虚拟账号**。普通账号列表列字段包括名称、用户名、密文、资产、平台、连接及操作。

列表上方提供：

- **最近 7 天**： 最近发现、最近登录、最近修改、最近改密、最近改密失败。
- **风险账号**： 长时间未登录、新增账号、弱密码、空密码、长时间未改密。
- **账号类型**： 全部、主机、网络设备、数据库、云、Web、目录服务、其它设置。

## 2 前提条件

- 已使用具备账号管理权限的账号登录 JumpServer（如系统管理员或组织管理员）。
- 创建账号前，目标资产须已存在于当前组织。创建资产请参见 [资产列表](../assets/assets_list.md)。
- 使用 **模版添加** 前，须先在 [账号模版](./account_template.md) 中准备模板。

:::important[组织范围]
当前列表只显示本组织内的账号。资产筛选、导入与授权也按当前组织生效。
:::

## 3 资产树与类型树

左侧默认显示 **资产树**，可按节点或具体资产查看关联账号。树标题旁可切换为 **类型树**，按资产类型查看。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_02.png" alt="图 2  切换资产树与类型树" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2  切换资产树与类型树</div>

节点旁的数字为该节点下的账号数量。

## 4 创建账号

可将同一账号关联到一台或多台资产。

1. 在普通账号列表单击 **创建**。
2. 在右侧抽屉 **新增账号** 中填写信息。
3. 单击 **确认**。若需放弃本次填写，单击 **还原**。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_03.png" alt="图 3  新增账号" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3  新增账号</div>

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"16px 0 8px"}}>表 1  新增账号字段说明</div>

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 基本设置 | 名称 | 必填。账号显示名，允许重复。 |
| 基本设置 | 用户名 | 登录资产所用用户名。 |
| 基本设置 | 特权账号 | 勾选后，批量改密、推送等操作可优先使用该账号。 |
| 基本设置 | 切换自 | 从此账号切换到当前账号，例如先登录特权账号再切换。 |
| 资产 | 资产 | 选择要关联的资产，可将同一账号关联到多台资产。 |
| 密码 | 密文类型 | **密码**、**SSH 密钥**、**SSH 证书**、**令牌** 或 **访问密钥**。 |
| 密码 | 密码 | 密文类型为密码时填写。可单击生成按钮随机生成。 |
| 密码 | 可改密 | 勾选后，账号改密计划可修改该账号在资产上的密码。 |
| 其它设置 | 账号策略 | 同一资产上已存在同名账号时的处理方式：**跳过**、**更新** 或 **失败**。默认 **失败**。 |
| 其它设置 | 激活 | 勾选后账号可用于登录。 |
| 其它设置 | 备注 | 选填。 |

## 5 模版添加

按已有账号模版批量向节点或资产添加账号。

1. 在普通账号列表单击 **模版添加**。
2. 在 **从模板添加账号** 中选择 **模板**，并选择 **节点** 或 **资产**。
3. 按需设置 **可改密**、**账号策略**、**激活** 和 **备注**。
4. 单击 **确认**。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_04.png" alt="图 4  从模板添加账号" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 4  从模板添加账号</div>

- **模板**： 必填。选择已创建的账号模版，可多选。
- **节点**： 将模板账号添加到所选节点下的资产。
- **资产**： 选择已创建的资产。
- **可改密**： 勾选后允许改密计划修改该账号密码。
- **账号策略**： **跳过**、**更新** 或 **失败**。
- **激活**： 勾选后账号可用于登录。
- **备注**： 选填。

:::note[账号模版]
列表按钮文案为 **模版添加**，抽屉标题为 **从模板添加账号**。账号模版的创建与维护见 [账号模版](./account_template.md)。
:::

## 6 导入与导出

列表右上角工具栏提供列设置、导出、导入和刷新。

导入对话框标题为 **导入 & 创建**，可选择 **创建** 或 **更新**。首次导入可先下载创建模板（CSV 或 XLSX），按提示填写后再上传。仅支持 csv / xlsx，且不超过 10M。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_05.png" alt="图 5  导入账号" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 5  导入账号</div>

导出账号信息时，系统会校验当前用户的 MFA。未开启 MFA 时，页面提示：该操作需要验证您的 MFA，请先开启并配置。

## 7 账号详情

在列表中单击账号 **名称**，打开详情抽屉。标题为「用户名@资产」。页签包括 **基本设置** 与 **活动**。右上角可 **编辑** 或 **删除**。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_06.png" alt="图 6  账号详情" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 6  账号详情</div>

### 7.1 基本设置

左侧 **基本信息** 展示 ID、名称、用户名、密文类型、标签、切换自、资产、版本、目录服务、来源、来源 ID、访问方式、连接性、改密状态、组织名称、激活、可改密、已托管密码、创建日期、更新日期、上次访问日期、校验日期、密码日期、创建者、备注等。

右侧 **快速更新**：

- **激活中**： 打开或关闭该账号。
- **特权账号**： 打开或关闭特权账号标记。
- **测试账号可连接性**： 单击 **测试**。
- **推送账号**： 单击 **推送**，将账号推送到资产。
- **查看密文**： 单击 **查看**。须已配置并完成 MFA 校验。
- **清除密文**： 单击 **清除**，移除已托管的密文。
- **切换自**： 单击 **选择**，指定切换来源账号。

:::warning[查看密文需 MFA]
查看密文、导出等涉及凭证的操作会校验当前用户的 MFA。本环境未开启 MFA 时，页面提示：该操作需要验证您的 MFA，请先开启并配置。
:::

### 7.2 活动

**活动** 展示该账号最近的登录与变更记录，例如用户使用该账号登录资产、创建当前资源等。

## 8 行内操作

操作列可编辑账号，并单击 **…** 打开更多菜单。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_07.png" alt="图 7  行内更多操作" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 7  行内更多操作</div>

行内更多菜单包括：

- **删除**： 删除该账号，不可逆。
- **编辑**： 修改账号信息。
- **编辑密文**： 修改密码或其它密文。
- **副本**： 克隆为新账号。
- **验证密文**： 校验当前密文是否可用于登录资产。
- **清除密文**： 清除已托管的密文。
- **历史密码**： 查看该账号的历史密码。
- **复制到资产**： 将账号复制到其它资产。
- **移动到资产**： 将账号改到其它资产。

列表 **连接** 列提供该账号对资产的连接入口。

## 9 批量操作

勾选账号前的复选框，单击 **更多操作**。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_08.png" alt="图 8  批量更多操作" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 8  批量更多操作</div>

可选：

- **测试所选**
- **清除密文**
- **编辑所选**
- **删除所选**

:::warning[删除不可恢复]
**删除** 与 **删除所选** 会移除账号数据，操作不可逆。清除密文后，需重新录入或推送才能继续托管该账号的凭证。
:::

## 10 虚拟账号

在授权规则中，可使用虚拟账号作为登录身份，而不必事先在每台资产上创建同名系统用户。单击 **虚拟账号** 页签查看内置虚拟账号。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/jumpserver/v5_admin_accounts_09.png" alt="图 9  虚拟账号" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 9  虚拟账号</div>

内置虚拟账号包括：

- **手动输入**（别名 `@INPUT`）： 登录时手动输入用户名和密码来连接。
- **同名账号**（别名 `@USER`）： 登录资产时，账号用户名与当前使用者的用户名相同。常用于目录用户（如 LDAP / AD）使用与 JumpServer 用户相同的用户名登录资产。
- **匿名账号**： 连接时不使用用户名和密码，仅支持 Web 类型和自定义类型资产。
- **指定账号**： 授权时指定使用的账号。

单击虚拟账号 **名称** 可查看详情（基本信息、活动），并可编辑备注等信息。
