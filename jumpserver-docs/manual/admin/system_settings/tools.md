## 1 功能简介

系统设置中的系统工具用于控制工作台是否开放 Ping、Telnet、Nmap、Tcpdump、Traceroute。路径：单击右上角齿轮进入 **系统设置**，选择 **系统工具**。

页签包括 **基本设置** 以及上述诊断工具。基本设置中的 **工作台中的工具**：若启用，具有 RBAC 权限的用户可使用工作台中的全部工具。工作台侧使用说明见 [系统工具](../workbench/other/system_tool.md)。
