## 1 功能简介

基本设置用于配置站点 URL 以及管理页面导航中的文档和支持链接。路径：单击右上角齿轮进入 **系统设置**，选择 **基本设置**。

- **当前站点 URL**：外部链接（如邮件）跳转到堡垒机时使用的地址，可填域名或 IP。
- **文档链接**：导航中的文档入口。
- **支持链接**：导航中的支持入口。

单击 **提交** 保存，或 **还原**。
