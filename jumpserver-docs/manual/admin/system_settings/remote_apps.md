## 1 功能简介

远程应用用于通过发布机或虚拟应用打开图形化工具。路径：单击右上角齿轮进入 **系统设置**，选择 **远程应用**。

页签包括 **远程应用**、**应用发布机**、**虚拟应用**、**应用提供者**。远程应用页可 **上传** 应用包，或打开 **应用市场**。上传时若应用不存在则创建，已存在则更新。
