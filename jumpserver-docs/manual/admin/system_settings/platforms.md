## 1 功能简介

平台是资产的分类，可指定协议、网关等，决定资产上是否启用某些功能。路径：单击右上角齿轮进入 **系统设置**，选择 **平台列表**。

页签包括主机、网络设备、数据库、Web、云服务、目录服务、自定义类型。列表列字段包括名称、资产、类别、类型及操作。可单击 **创建**。

## 2 前提条件

- 已使用系统管理员账号登录 JumpServer。

## 3 使用说明

创建资产时选择平台。也可新建平台并指定基础类型。SFTP 默认目录等行为在对应平台上配置，而不是改系统内置默认平台。
