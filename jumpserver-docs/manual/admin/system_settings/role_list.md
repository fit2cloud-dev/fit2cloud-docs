## 1 功能简介

角色列表用于查看和创建系统角色、组织角色。路径：单击右上角齿轮进入 **系统设置**，选择 **角色列表**。

页签包括 **系统角色** 和 **组织角色**。列表列字段包括名称、用户、内置的、备注及操作。内置角色不可删除。系统角色默认包括系统管理员、系统审计员、系统组件、系统操作员等。

## 2 前提条件

- 已使用系统管理员账号登录 JumpServer。

## 3 创建角色

选择 **系统角色** 或 **组织角色**，单击 **创建**。创建后进入详情配置权限，以界面为准。
