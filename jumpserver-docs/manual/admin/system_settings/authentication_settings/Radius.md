## 1 功能简介

Radius 用于对接 Radius 服务器认证。路径：单击右上角齿轮进入 **系统设置**，选择 **认证设置**，页签 **Radius**。

字段包括 **Radius** 开关、**主机**、**端口**、**密文**、**使用 radius OTP**、**组织**。单击 **提交** 保存。

- 已使用系统管理员账号登录 JumpServer。
- 已有可用的 Radius 服务。
