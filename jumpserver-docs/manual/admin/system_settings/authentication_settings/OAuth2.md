## 1 功能简介

OAuth2 用于对接 OAuth 2.0 身份提供方。路径：单击右上角齿轮进入 **系统设置**，选择 **认证设置**，页签 **OAuth2**。

字段包括 **OAuth2** 开关、**服务提供商**、**图标**、**客户端 ID**、**客户端密钥**、**客户端认证方式**、**范围**、**授权端点地址**、**Token 端点地址**、**用户信息端点地址**、**注销会话端点地址**、**映射属性**、**组织**、**总是更新用户信息**、**同步注销**。单击 **提交** 保存。

## 2 前提条件

- 已使用系统管理员账号登录 JumpServer。
- 已在身份提供方创建应用。
