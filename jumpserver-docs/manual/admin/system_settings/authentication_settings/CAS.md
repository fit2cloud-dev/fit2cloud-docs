## 1 功能简介

CAS 用于对接 CAS 单点登录。路径：单击右上角齿轮进入 **系统设置**，选择 **认证设置**，页签 **CAS**。

字段包括 **CAS** 开关、**服务端地址**、**回调地址**、**版本**、**映射属性**、**组织**、**同步注销**。单击 **提交** 保存。
