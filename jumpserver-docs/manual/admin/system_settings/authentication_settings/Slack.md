## 1 功能简介

Slack 认证用于使用 Slack 登录 JumpServer。路径：单击右上角齿轮进入 **系统设置**，选择 **认证设置**，页签 **Slack**。

字段包括 **Slack** 开关、**Client ID**、**Client secret**、**Client bot token**、**映射属性**、**组织**。单击 **提交** 保存。
