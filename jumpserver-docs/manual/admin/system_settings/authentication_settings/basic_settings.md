## 1 功能简介

认证设置的基本设置用于配置登录相关的通用选项。路径：单击右上角齿轮进入 **系统设置**，选择 **认证设置**，页签 **基本设置**。

- **邮件后缀**
- **忘记密码链接**
- **启用登录跳转提示**

**集成** 页签按通用、单点登录、身份提供者等分组展示各认证方式入口。具体协议在后续页签中配置。单击 **提交** 保存。
