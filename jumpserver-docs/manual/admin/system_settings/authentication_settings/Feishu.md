## 1 功能简介

飞书认证用于使用飞书登录 JumpServer。路径：单击右上角齿轮进入 **系统设置**，选择 **认证设置**，页签 **飞书**。

字段包括 **飞书** 开关、**App ID**、**App secret**、**映射属性**、**组织**。单击 **提交** 保存。

## 2 前提条件

- 已使用系统管理员账号登录 JumpServer。
- 已在飞书开放平台创建应用。
