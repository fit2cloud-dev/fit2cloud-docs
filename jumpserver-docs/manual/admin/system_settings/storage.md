## 1 功能简介

存储设置用于配置会话录像等对象存储，以及命令存储。路径：单击右上角齿轮进入 **系统设置**，选择 **存储设置**。

页签包括 **对象存储** 和 **命令存储**。列表列字段包括名称、类型、备注、默认及操作。可单击 **创建**。
