## 1 功能概述

- 通过点击页面右上角小齿轮进入 **系统设置** 页面。
- 系统设置是 JumpServer 全局设置的操作入口，通过系统设置可以配置 JumpServer 角色、平台、远程应用、安全等各类型的系统参数。
