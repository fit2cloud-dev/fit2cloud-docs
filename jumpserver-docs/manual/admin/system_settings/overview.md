## 1 功能简介

系统设置用于配置 JumpServer 的全局参数。单击页面右上角齿轮进入 **系统设置**。v5 无独立「概览」页，默认打开 **基本设置**。

左侧模块包括基本设置、组织管理、角色列表、平台列表、AI 助手、通知设置、功能设置、认证设置、存储设置、组件设置、远程应用、安全设置、界面设置、系统工具、系统任务、设备管理、许可证。
