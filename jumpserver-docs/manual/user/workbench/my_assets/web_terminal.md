## 1 功能简介

1. **切换组织按钮** 点击可以切换当前组织
2. **搜索资产按钮** 可以输入对应资产名称快速筛选匹配资产，支持模糊匹配
3. **文件管理入口** 点击可以进入[文件管理](file_explorer.md)页面
4. **我的资产** 展开可以查看当前组织中获得 **授权** 使用的资产如果发现为空，请确认 **管理员** 是否配置好资产授权
5. **我的收藏** 可以查看自己设置为收藏的资产，设置方法为右键对应资产设置或者在工作台资产链接页面设置
6. **脚本库** 可以编辑一些常用的脚本存放在这，方便在资产上执行某些操作
7. **AI助手** 可以进行对资产状态的查询，可直接接手资产进行操作，需要管理员在 **系统设置** 中配置对应的智能体后使用
8. **服务器状态以及文件管理** 可以查看目前连接的服务器的资源占用情况以及进行文件传输

## 2 资产连接步骤

1. **选择资产** 在右侧列表中选择想要连接的资产
2. **选择协议** 不同的资产在配置页面可以配置不同的连接方式如Linux资产可以配置ssh，sftp，vnc等协议
3. **选择账号** 选择管理员给授权的资产账号
4. **连接资产** 选择是在web控制台进行资产连接还是使用客户端，或者其他的连接方式，如远程应用
5. **高级选项** 可以选择终端的字符集以及其他配置
6. **自动连接** 勾选之后再次点击左侧的资产，会直接复用上次的连接信息，如果想要重新选择连接方式以及账号，右键资产选择连接可以重新选择
7. **连接按钮** 点击之后创建一个资产连接
