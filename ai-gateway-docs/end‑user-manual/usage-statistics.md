## 1 功能说明

用量统计页汇总展示网关在指定时间范围内的模型调用总量与分布，帮助管理员掌握各供应商、模型、用户的使用情况。页面由筛选区、总览卡片和分布表格组成。

<div align="center">图 1  用量统计页</div>

## 2 筛选项

页面顶部提供以下筛选项，用于切换统计范围。

**表 1  用量统计筛选项**

| 筛选项 | 说明 |
|---|---|
| 用户 | 按指定用户过滤统计范围。 |
| 供应商 | 按上游供应过滤统计范围。 |
| API 类型 | 按 API 类型过滤统计范围。 |
| 时间维度 | 选择统计的时间范围，默认为「近 30 天」。 |
| 请求模型 | 输入请求模型名称进行精确过滤。 |

## 3 总览指标

筛选区下方以卡片形式展示所选范围内的核心指标。

**表 2  用量统计总览指标**

| 指标 | 说明 |
|---|---|
| 请求量 | 范围内的模型调用总次数。 |
| 输入 Token | 范围内累计的输入 Token 数。 |
| 输出 Token | 范围内累计的输出 Token 数。 |
| 总 Token | 输入与输出 Token 的合计。 |
| 缓存 Token | 范围内命中缓存的 Token 数。 |

## 4 分布表格

总览卡片下方按多个维度展示用量分布，各表格列包含「请求量」「总 Token」「缓存 Token」。

**表 3  用量统计分布维度**

| 分布维度 | 说明 |
|---|---|
| 按供应商分布 | 统计各上游供应商的用量。 |
| 按模型分布 | 统计各请求模型的用量。 |
| 按模型组分布 | 统计各模型组的用量。 |
| 按上游账号分布 | 统计各上游账号的用量，已删除账号会标注「已删除」。 |
| 按用户组分布 | 统计各用户组的用量。 |
| 按用户分布 | 统计各用户的用量。 |

:::tip 排查用量异常
当某维度出现「未关联」「未知」等条目时，通常表示对应请求未能关联到供应商或账号。可结合调用日志进一步定位来源。
:::
