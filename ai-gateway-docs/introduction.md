# 功能介绍

## 1 功能简介

1Panel AI 网关（Gateway）是 1Panel 提供的企业级 AI 模型网关服务，将多个大语言模型统一聚合为一个 OpenAI 兼容接口，供业务应用统一调用。控制台包含以下三个功能模块：

- **模型广场**：查看网关已接入的全部模型，按文本、文生图、向量分类筛选，并获取接入地址与接口说明。
- **API Keys**：创建与管理调用凭证。所有对网关接口的调用都必须携带 API Key 完成认证。
- **用量统计**：按 API Key 与时间维度查看模型调用的用量数据。

## 2 前提条件

- 已开通 1Panel AI 网关服务，并获取控制台地址（如 `https://1router.1panel.cn`）。
- 已获取控制台账号（由管理员分配）。
- 使用 Chrome、Edge 等现代浏览器访问。

## 3 登录控制台

1. 在浏览器地址栏输入控制台地址，例如 `https://1router.1panel.cn`。未登录时自动跳转至登录页。
2. 输入**用户名**与**密码**。
3. 单击**登录**，登录成功后进入模型广场页面。
