# 用量统计

## 1 功能入口

在左侧导航栏选择**用量统计**，进入用量统计页面。

## 2 界面说明

页面顶部提供 **API Key** 与**时间维度**两个筛选条件（如「近 30 天」），右上角提供**刷新**按钮。

页面主体包含两部分：

- **统计卡片**：展示请求量、输入 Token、输出 Token、总 Token、缓存 Token 五项汇总指标。
- **用量趋势图**：按日期展示 Token 用量趋势，支持按**模型**或 **API Key** 两种维度切换，图例标注各模型名称。

未产生调用记录时，页面显示空态提示「暂无用量数据」，并附说明「创建 API Key 并调用模型后，可在这里查看用量」，同时提供**创建 API Key** 快捷按钮。
