## 功能简介

1Panel AI网关的用户管理用于集中管理控制台的登录账号。每个账号绑定一个角色和一个用户组，并保留自身的登录密码、登录失败计数、最近登录时间等安全状态。账号可被启用、禁用、重置密码和解锁；当系统内只剩一名管理员账号时，1Router 会自动启用唯一管理员保护，禁止对该账号执行破坏性操作，避免出现无人可登录的失控状态。

## 2 功能入口

登录 1Router 控制台后，在左侧菜单中选择 **用户**，即可进入用户管理页面。页面默认以表格形式列出全部用户账号，并显示用户名、角色、用户组、状态、最近登录、创建时间和操作入口等关键字段，布局与图 1 一致。

## 3 添加用户

添加用户的过程即填写用户名、所属用户组和初始密码并保存。其中用户名与密码均有格式约束，系统会在表单中实时校验，全部通过后才能保存成功。

### 3.1 打开添加用户表单

在用户管理页面左上角单击 **添加用户** 按钮，系统会从右侧滑出「添加用户」抽屉。抽屉按从上到下的顺序依次提供 用户名、用户组、新密码、确认新密码 四个必填项，底部有 取消 与 保存 按钮。

### 3.2 用户名

**用户名** 必须为 3 至 64 位 ASCII 字符，且以字母或数字开头，只允许包含字母、数字、点（`.`）、下划线（`_`）和连字符（`-`）。系统会以实时校验的方式提示格式是否合法。用户名一经保存不可修改，如需更换通常需要重新创建账号。

### 3.3 初始密码与确认密码

**新密码** 长度必须为 12 至 128 字节，填写框下方会以提示文字「密码长度须为 12 至 128 字节」进行实时校验。**确认新密码** 必须与新密码保持一致，否则无法保存。出于安全考虑，建议在控制台完成添加后，要求新账号首次登录时立即修改密码。

### 3.4 保存

填写完成后单击抽屉底部的 **保存** 按钮，新用户即出现在用户列表中。若必填项校验未通过，系统会标红对应字段并阻止提交，按提示修正后再次保存即可。首次登录时，该账号会被强制要求修改密码。

## 4 管理用户

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3  用户行内操作</div>

在用户列表的操作列，每个普通用户账号均提供 启用/禁用 开关、 重置密码、 编辑、 删除 四类操作，单击对应控件即可对账号进行维护。受账号当前状态影响，操作列会动态显示不同控件：被锁定的账号额外出现 解锁，受唯一管理员保护的账号则不显示危险操作。

### 4.1 编辑

单击 **编辑** 打开账号编辑抽屉。普通用户可调整所属用户组；用户名、创建时间等基础信息保持不变。若在编辑过程中需要调整登录凭据，请配合 重置密码 操作完成。

### 4.2 启用/禁用

操作列最左侧的开关用于切换账号的启用状态。**禁用** 后的普通用户：

- 其已建立的浏览器会话会被立即删除；
- 该账号下已签发的 API Key 停止接受调用，避免停用账号继续被使用。

重新启用后，账号可正常登录并恢复 API Key 调用。

### 4.3 重置密码

单击 **重置密码** 打开重置密码抽屉。管理员可在抽屉中设置新的登录密码，确认后保存。重置密码过程会同时：

- 设置新密码；
- 清除账号当前的登录失败计数与锁定截止时间；
- 注销该账号现有的所有浏览器会话。

被重置密码的账号在下一次登录时同样需要强制修改密码。

### 4.4 解锁

当账号因连续登录失败被系统自动锁定时，操作列会出现 **解锁** 控件。单击 **解锁** 仅清除登录失败计数和锁定截止时间，不会修改密码，也不会影响其他会话。解锁后该账号可继续按原密码登录。

### 4.5唯一管理员保护

当系统内仅剩一名管理员账号时，该账号会被唯一管理员规则保护：

- 不可被 禁用；
- 不可被 重置 为普通用户；
- 不可执行任何会导致「无管理员可登录」状态的操作；
- 不显示 重置密码、编辑、删除 控件。

只有当系统内出现其他管理员后，该限制才会解除，账号恢复常规操作。
