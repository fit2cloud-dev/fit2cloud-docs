## 1 功能简介

**基准测试**用于对模型服务进行基准测试，评估不同请求长度和并发配置下的吞吐量、首 Token 延迟及请求耗时等指标。页面由**基准测试**与**设置**两个页签组成。在**设置**中准备 Benchmark 镜像与测试方案，在**基准测试**中创建测试并查看测试记录，单击记录中的**报告**进入结果报告。报告提供**结果指标**、**测点**、**日志**、**执行环境**与**测试配置**五个页签，并支持导出 **JSON**、**CSV**、**HTML** 与 **ZIP** 四种格式。

## 2 前置条件

- 已安装 1Panel 企业版，本文基于界面显示的**企业版 v2.nightly** 编写。
- 已在**模型服务**中登记待测试的模型服务，本文示例为 `vLLM-Qwen3.6-35B-A3B`。
- 已准备 **Benchmark 镜像**与至少一个**测试方案**，两项均就绪后即可创建基准测试。
- 已准备与模型匹配的**分词器**，用于测试文本的 Token 编码及统计。

在**设置**页，顶部提示**请先准备 Benchmark 镜像和测试方案，两项均就绪后即可创建基准测试。**页面分为两组。**Benchmark 镜像**显示**镜像名**与**需拉取**状态，提供**拉取镜像**。**测试方案**显示**已就绪**，提供**创建**，并说明**测试方案用于定义请求参数、并发配置及执行规则，请至少准备一个可用方案。**下方表格按**名称**、**场景**、**描述**、**操作**列出内置方案，每行提供**克隆**：

- **快速验证**：**内置**，**共 1 个场景**，单请求验证服务连通性与测量流程。
- **常规测试**：**内置**，**共 3 个场景**，短、中、长三类负载，适合日常性能测试。
- **完整测试**：**内置**，**共 7 个场景**，多场景、多并发与重复测量，包含长输入和共享前缀。

## 5 查看测试报告：场景与并发对照

在列表行单击**报告**进入报告页。页面左上提供**返回**与报告名称，本文示例为 `benchmark-20261110183053-93486`；下方提供 **JSON**、**CSV**、**HTML**、**ZIP** 四个导出按钮。页签为**结果指标**、**测点**、**日志**、**执行环境**与**测试配置**，本文截图展示**结果指标**页签，如图 3 所示。

表格下方提供**场景**与**并发数**两个筛选下拉，右侧显示**有效 / 总次数**。本文示例为**Quick**与**1 - 不限速（最大吞吐）**，有效 / 总次数为 <code>1 / 1</code>。筛选区下方的结果分类行显示**结果分类：serve（常规测试）**、**输入 / 输出 Token: 32 → 16**、**请求速率: 不限速（最大吞吐）**、**共享前缀比例: 0%**、**请求数量: 1** 与**预热请求数: 0**。

:::note[数据口径]
汇总仅使用成功且无请求异常的重复测试，显示中位数和最小/最大值。P99 是每次测试 P99 的中位数；缓存和外部流量未受控。共享前缀比例为配置的前缀 Token 数占输入长度的比例，不代表实测缓存命中率。
:::
