# 使用 1Panel 可视化安装 Halo

**Halo** 是一个简洁、高效的开源建站平台。它提供了易于使用的界面和丰富的功能，使用户可以轻松地创建个人博客或专业网站。

## 1. 打开应用商店

进入 1Panel 控制台后，点击左侧菜单的 **「应用商店」**。

![image-20251016110510084](/img/1panel/app/appstores.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 1 打开应用商店</div>

## 2. 搜索 Halo 并安装

在右上角搜索框输入 **Halo**，点击应用卡片进入详情页，选择 **安装**。

![image-20251017160924774](/img/1panel/app/halo.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2 搜索 Halo 并安装</div>

## 3. 配置安装参数

 你可以根据需要配置，这里需要配置数据库服务

- **名称** (输入框内可自定义应用名称，默认为 halo)
- **版本** (下拉选择所需的 Halo 版本)
- **数据库服务** (选择用于存储数据的数据库服务，例如 MySQL)
- **数据库名** (为应用创建的数据库名称)
- **数据库用户** (用于连接数据库的用户名)
- **数据库用户密码** (数据库用户的密码)
- **外部访问地址** (设置 Halo 博客的外部访问 URL)
- **端口** (应用的访问端口，默认为 8090)
- **端口外部访问** (开启后，将允许从外部网络访问此应用端口)

确认设置无误后，点击 **确认** 按钮开始安装。

![image-20251017161134886](/img/1panel/app/halo_install.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 3 配置安装参数——安装 Halo 的参数配置</div>

等待安装完成即可

## 4. 访问 Halo 服务

配置默认访问地址，已配置则忽略此步骤

![image-20251016172322315](/img/1panel/app/setting_ip.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 4 访问 Halo 服务界面</div>

返回应用商店，点击 **跳转** 即可访问 Halo 服务

![image-20251017161906552](/img/1panel/app/halo_jump.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 5 访问 Halo 服务——打开 Halo 服务地址</div>

设置配置信息，完成初始化

![image-20251017162019192](/img/1panel/app/halo_view.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 6 访问 Halo 服务界面</div>

输入用户名密码登录，即可使用

![image-20251017162114732](/img/1panel/app/halo_login.png)
<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 7 访问 Halo 服务登录页面</div>
