本页汇总 DataEase 技术交流群中用户咨询频率较高的常见问题及处理方式，内容持续更新。

## 1 安装部署

### 1.1 V2能否直接升级到V3

**问题**：DataEase V2 能否在同一台服务器上直接升级到 V3？

**处理方式**：

不支持直接升级。V2 与 V3 架构不兼容，安装脚本会检测当前版本并阻止升级。需在新环境安装 V3，并使用官方迁移工具将 V2 数据迁移至 V3。

迁移步骤请参阅[V2-V3 数据迁移指南](../installation/data_migration.md)

### 1.2 外部数据库安装后缺表或Schema配置错误怎么办？

**问题**：使用外部数据库（如PostgreSQL）进行脚本化安装时，提示缺表或Schema配置错误，应如何修正？

**处理方式**：

DataEase 安装脚本会自动在目标库中建表并写入初始数据。若出现缺表或 Schema 错误，通常是因为 `install.conf` 中的 `DE_DB_SCHEMA` 配置不正确或为空。

请在安装目录的 `install.conf` 文件中修改 `DE_DB_SCHEMA` 为正确的 Schema 名称（PostgreSQL 默认为 `public`，若未指定则可能默认为用户名或空），保存后执行 `dectl restart` 重启服务。

详细配置参数请参阅[外部数据库部署](../installation/multi_database_deployment.md)

### 1.3 桌面版在哪下载？收费吗？

**问题**：DataEase 桌面版在哪里下载，是否需要付费？

**处理方式**：

DataEase v3 桌面版尚未发布，目前无法下载。桌面版为免费下载，不收取会员费。

### 1.4 V1 大屏能否迁移到 V3？

**问题**：DataEase 1.7 的大屏能否迁移到 3.2.1，有没有迁移工具？

**处理方式**：

不支持。V1 版本没有跨版本升级方案，官方迁移工具要求源端为 DataEase 2.0 且镜像标签为 v2.10.26 及以上，V1 与 V3 模板也不互通，只能在新版本中重新创建。

V2 迁移至 V3 的步骤请参阅[V2-V3 数据迁移指南](../installation/data_migration.md)

### 1.5 v3.2.1 添加数据源报插件功能企业版才有？

**问题**：离线安装 DataEase v3.2.1 后，添加数据源和导入文件都报错提示插件功能企业版才有，怎么处理？

**处理方式**：

该问题由 v3.2.1 版本自身缺陷导致，研发正在修复。可先备份 `dataease3.0` 目录，再将 docker compose 文件中的镜像名称改为 3.2.0，切换到 3.2.0 版本启动使用。

### 1.6 V3 如何备份和还原？

**问题**：DataEase V3 有没有备份和还原的命令或手册？

**处理方式**：

V3 目前没有备份和还原的指令。使用内置数据库时，直接备份整个 `dataease3.0` 目录即可，操作前请先做好备份。

## 2 数据源与数据集

### 2.1 跨源查询 Doris 报错怎么办？

**问题**：在多源跨源查询时，Doris 数据源因自动添加的分页语法不支持而报错，该如何处理？

**处理方式**：

在近期版本中，为了修复安全漏洞，系统将 MySQL/Doris 类数据源的底层驱动切换为了 MariaDB 驱动。驱动替换后，跨源计算引擎（Calcite）在识别数据库元数据时未能准确匹配到 MySQL/Doris 方言，回退到了默认的 ANSI 标准方言，生成了 OFFSET ... FETCH ... 分页语法，导致 Doris 执行时出现语法解析错误。
该问题已修复，将在后续版本（v2.10.28 及 v3.2.0）中发布。

### 2.2 V3 是否支持跨源查询？

**问题**：DataEase V3 是否支持跨源查询？

**处理方式**：

V3 支持跨源查询。使用需在系统设置--系统参数--基础设置中关闭限制数据集跨源。

### 2.3 自定义SQL数据集保存提示超时怎么办？

**问题**：创建自定义 SQL 数据集时，SQL 能运行出结果，但保存时一直提示超时，是什么原因？

**处理方式**：

先在系统设置--系统参数--基础设置中调大请求超时时间，再到对应数据源的「高级设置」中调大查询超时时间。

### 2.4 API 返回的 JSON 数据如何解析成字段？

**问题**：调用 API 返回 JSON 格式数据，如何让其中的字段在报表中正常展示？

**处理方式**：

通过 API 数据源接入，并在配置时启用 JsonPath 解析。若【是否指定JsonPath】未启用，系统会自行解析，且可以组合不同层级的字段；若勾选是，则需自行填写 JsonPath，系统按该值解析，此时不可组合不同层级的字段。

详细配置步骤请参阅[配置 API 数据源](../user_manual/datasource_configuration_api.md)

### 2.5 自定义 SQL 数据集支持临时表吗？

**问题**：在 DataEase 中创建自定义 SQL 数据集时，SQL 里能使用临时表吗？

**处理方式**：

SQL 数据集只支持单条查询语句，执行时会被包装成子查询，无法执行 CREATE TEMPORARY TABLE 这类 DDL；且连接来自连接池，临时表的会话级生命周期也无法保证。需要中间结果时请用子查询或 CTE（WITH ... AS）​ 替代。

### 2.6 DataEase 是否支持华为 GaussDB 数据源？

**问题**：DataEase 支持连接华为高斯（GaussDB）数据库吗？

**处理方式**：

支持。在【数据准备】中新建数据源，OLTP 分类下选择 GaussDB 图标即可配置连接，系统内置华为 GaussDB JDBC 驱动（`com.huawei.gaussdb.jdbc.Driver`），端口常见默认为 8000，并支持选择 Schema 后加载对应模式下的数据表。

详细配置步骤请参阅[配置 GaussDB 数据源](../user_manual/datasource_configuration/GaussDB_datasource_configuration.md)

### 2.7 SQL 数据集文本字段前导零丢失怎么办？

**问题**：用 SQL 生成数据集后，文本型字段以 0 开头的前导零丢失了，如何保留？

**处理方式**：

在数据集字段管理中将该字段的类型改为文本型，前导零即可保留。

### 2.8 明细数据如何脱敏显示？

**问题**：明细数据中的手机号、姓名等敏感信息，如何设置成脱敏显示（如 138****8888、王*某）？

**处理方式**：

在数据集编辑界面通过【新建计算字段】对原字段进行处理，字段表达式中引用对应数据源的数据库函数（如 MySQL 数据源的 IF、CASE WHEN 等）生成脱敏后的新字段，再在图表中使用该字段。

详细操作请参阅[新建计算字段](../user_manual/dataset_design.md)

## 3 仪表板与图表

### 3.1 日期范围筛选器能否手动输入日期？

**问题**：日期范围筛选器跨年度选择日期很麻烦，能否手动输入开始和结束日期？

**处理方式**：

目前不支持手动输入日期。可使用时间范围查询组件左侧的快捷日期选择方案：需将组件类型设为「时间范围」，时间粒度选择「年月日」，此时左侧会提供本周、本月、本季度等常用区间快捷选项。

### 3.2 分享链接能否加密或分用户设密码？

**问题**：DataEase 社区版仪表板分享链接可以加密吗？能否单独给一个 ticket 设置密码，或分用户设置不同密码？

**处理方式**：

分享链接支持密码保护：在分享设置中勾选「密码保护」，他人访问该链接时需输入密码才能查看。不支持为单个 ticket 单独设置密码，也不支持分用户设置不同密码。

### 3.3 桌面版能否生成分享链接？

**问题**：做好数据看板后想生成链接分享给别人直接打开，桌面版能做到吗？

**处理方式**：

桌面版不支持分享链接，需要下载服务器版。
