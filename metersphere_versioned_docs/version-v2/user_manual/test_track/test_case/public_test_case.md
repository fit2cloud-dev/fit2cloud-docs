:::note

公共用例库为同一工作空间下的不同项目均可共享使用的【公共用例】，不同项目可【添加】用例至公共用例库，和【复制】公共用例库中的用例。

:::

![!公共用例库入口](/img/metersphere-v2/track/公共用例库入口.png)

图 1  公共用例库入口

:::note

公共用例库列表字段不展示自定义的模板字段

:::

![!公共用例库页面](/img/metersphere-v2/track/公共用例库页面.png)

图 2  公共用例库页面

## 1 启动公共用例库

:::note

项目管理员可到【项目设置】-【更多选项】-【应用管理】页面下，开启【启动公共用例库】设置。

:::

![!公共用例库选择数据](/img/metersphere-v2/track/启动公共用例库.png)

图 3  启动公共用例库

## 2 添加用例至公共用例库

:::note

点击用例【ID】或者【编辑】按钮，点击【添加到公共用例库】。

:::

![!公共用例库批量处理](/img/metersphere-v2/track/添加用例至公共用例库.png)

图 4  添加用例至公共用例库

## 3 从公共用例库中复制用例

:::note

复制公共用例库中的用例到自己的项目模块中。

:::

![!公共用例库批量处理](/img/metersphere-v2/track/复制公共用例库中的用例.png)

图 5  复制公共用例库中的用例
