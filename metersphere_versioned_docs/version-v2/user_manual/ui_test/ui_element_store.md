## 1 创建元素

:::note

切换到【UI测试】模块下的【元素库】页面，点击【创建元素】，输入元素字段名，选择所属模块和定位类型，然后输入元素定位的表达式和备注。

:::

![创建元素](/img/metersphere-v2/ui_test/创建元素.png)

图 1  创建元素

## 2 元素定位

:::note

元素定位支持多种方式，包括 id、name、class、tag、link、plink、css、xpath、lable、value、index，这里以 xpath 为例。输入必填信息后，点击确认即可保存元素。

:::

![元素定位](/img/metersphere-v2/ui_test/元素定位1.png)

图 2  元素定位（1）

:::note

在页面上点击你要定位的元素，然后右键选择【检查】。

:::

![元素定位](/img/metersphere-v2/ui_test/元素定位2.png)

图 3  元素定位（2）

:::note

右键选择 Copy-Copy XPath 即可获得该元素的 xpath 路径。

:::

![元素定位](/img/metersphere-v2/ui_test/元素定位3.png)

图 4  元素定位（3）

## 3 编辑元素

:::note

在元素库列表，点击【编辑】键，可以修改元素属性，修改之后点击确认即可保存。

:::

![编辑元素](/img/metersphere-v2/ui_test/编辑元素.png)
